# Dummy Kart

A battle kart racer for the browser, starring characters from the other DemiDummy games. Twelve karts on the grid
every race: you, up to eleven friends, and the computer in whatever seats are left. Four tracks: a road of light in
space, laps of the yard around a very large tree with opinions, a haunted manor at midnight, and a toy track across
a giant developer's desk.
**Play it at https://demidummy.github.io/dummy-kart/**

One player clicks **Host a room** and shares the 4-letter code; everyone else types it and clicks Join.
Keyboard or gamepad. "How to play" is on the title screen.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
