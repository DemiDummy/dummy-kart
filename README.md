# Dummy Kart

A battle kart racer for the browser, starring characters from the other DemiDummy games. Eight karts on the grid
every race: you, up to seven friends, and the computer in whatever seats are left. Two tracks: a road of light in
space, and laps of the yard around a very large tree with opinions.
**Play it at https://demidummy.github.io/dummy-kart/**

One player clicks **Host a room** and shares the 4-letter code; everyone else types it and clicks Join.
Keyboard or gamepad. "How to play" is on the title screen.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
